# Pinecone Index Management

Index management operations for Pinecone vector database.

## Key Operations
- **Create Index** - Create serverless or pod-based indexes
- **List Indexes** - Retrieve all indexes in a project
- **Describe Index** - Get detailed index information
- **Delete Index** - Remove indexes and all data
- **Configure Index** - Update index settings

## Index Types
- **Serverless** - Auto-scaling, pay-per-use indexes
- **Pod-based** - Fixed-capacity indexes with dedicated resources

## tofu-aicl Integration
Essential for managing vector database infrastructure in AI workflows.
