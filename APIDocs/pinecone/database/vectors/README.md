# Pinecone Vector Operations

Core vector operations for storing, querying, and managing vectors in Pinecone indexes.

## Key Operations
- **Upsert** - Insert or update vectors with metadata
- **Query** - Semantic similarity search
- **Fetch** - Retrieve vectors by ID
- **Delete** - Remove vectors from index
- **Update** - Modify vector values or metadata

## Vector Types
- **Dense Vectors** - Traditional embeddings (most common)
- **Sparse Vectors** - High-dimensional sparse representations
- **Hybrid Vectors** - Combined dense and sparse for enhanced search

## tofu-aicl Integration
Essential for AI workflows requiring vector storage and semantic search capabilities.
