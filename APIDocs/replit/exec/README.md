# Exec API

Execute shell commands and spawn processes within the Replit workspace.

## Key Methods
- `exec.spawn()` - Spawn process with streaming output
- `exec.exec()` - Execute command and return result

## tofu-aicl Integration
Critical for AI workflows that need to run build commands, tests, or generated scripts.

## Files
- `methods.md` - Method documentation and signatures
- `examples.md` - Usage examples and patterns
- `tofu-aicl-integration.md` - Provider implementation for command execution
