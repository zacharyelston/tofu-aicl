# Messages API

Display custom toast notifications in the Replit workspace.

## Key Methods
- `messages.showConfirm()` - Show confirmation dialog
- `messages.showError()` - Show error notification
- `messages.showNotice()` - Show info notification
- `messages.showWarning()` - Show warning notification
- `messages.hideMessage()` - Hide specific message
- `messages.hideAllMessages()` - Hide all messages

Essential for providing user feedback during AI workflow execution.
