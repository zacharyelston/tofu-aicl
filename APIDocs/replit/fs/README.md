# Filesystem API

Comprehensive file and directory operations within Replit workspace.

## Key Operations
- **Files**: read, write, delete, copy, move
- **Directories**: create, read, delete
- **Watching**: monitor file/directory changes
- **Permissions**: granular read/write access control

## tofu-aicl Integration
