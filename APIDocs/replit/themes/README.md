# Themes API

Access and utilize theme data and color tokens in Replit extensions.

## Key Methods
- `themes.getCurrentTheme()` - Get current theme information
- `themes.getCurrentThemeValues()` - Get theme color values
- `themes.onThemeChange()` - Listen for theme changes
- `themes.onThemeChangeValues()` - Listen for theme value changes

## tofu-aicl Integration
Useful for AI workflows that generate UI components matching user's theme preferences.
