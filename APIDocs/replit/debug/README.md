# Debug API

Log data, warnings, and errors to the Extension Devtools.

## Key Methods
- `debug.info()` - Log info messages
- `debug.warn()` - Log warning messages
- `debug.error()` - Log error messages
- `debug.log()` - General logging

## tofu-aicl Integration
Essential for debugging AI workflows and monitoring provider execution.
