# Manifest API

Extension configuration reference for the extension.json manifest file.

## Key Properties
- Extension metadata (name, version, description)
- Permissions and scopes
- File handlers and tools
- Background pages and scripts
- Cover images and branding

## tofu-aicl Integration
Essential for configuring Replit provider extensions with proper permissions and capabilities.

## Files
- `properties.md` - Manifest properties and configuration
- `permissions.md` - Permission system and scopes
- `examples.md` - Example manifest configurations
- `tofu-aicl-integration.md` - Provider extension manifest examples
