# Replit Extensions API Documentation

Complete documentation for Replit Extensions API with tofu-aicl integration examples.

## API Modules

### Core APIs
- **init/** - Extension initialization and handshake
- **auth/** - User authentication and JWT tokens (experimental)
- **data/** - GraphQL API access for users and Repls

### Workspace APIs
- **fs/** - File system operations and watching
- **exec/** - Shell command execution
- **session/** - User coding session tracking

### UI APIs
- **themes/** - Theme and color management
- **messages/** - Toast notifications and user messages
- **editor/** - Editor preferences and settings

### Extension APIs
- **commands/** - Custom command registration
- **me/** - Extension context information
- **background/** - Background script management

### Development APIs
- **debug/** - Extension debugging and logging
- **manifest/** - Extension configuration reference

## tofu-aicl Integration

Each API module includes:
- Method documentation
- Usage examples
- tofu-aicl provider integration patterns
- Security considerations

## Developer Frameworks

Replit provides templates and frameworks for:
- React Extensions
- HTML/CSS/JS Extensions
- AI-powered extensions
- API development tools

## Getting Started

1. Review `init/` for extension bootstrap
2. Check `auth/` for user authentication
3. Explore `fs/` for file operations
4. See individual API directories for detailed documentation
