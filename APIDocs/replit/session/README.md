# Session API

Access and manage the current user's coding session in the Replit workspace.

## Key Methods
- `session.onActiveFileChange()` - Listen for active file changes
- `session.getActiveFile()` - Get currently active file

## tofu-aicl Integration
Essential for context-aware AI workflows that respond to user's current work.
