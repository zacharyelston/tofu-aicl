# Azure API Documentation

Complete documentation for Azure cloud service APIs with tofu-aicl integration examples.

## API Modules

### AI & Cognitive Services
- **openai-service/** - Azure OpenAI API (chat, completions, embeddings)
- **cognitive-services/** - Vision, Speech, Language, Translator APIs
- **ai-search/** - Azure AI Search (formerly Cognitive Search)
- **content-safety/** - Content moderation and safety APIs
- **document-intelligence/** - Document processing and OCR

### Storage & Data
- **storage/** - Blob Storage, File Storage, Queue Storage
- **cosmos-db/** - NoSQL database operations
- **sql-database/** - Azure SQL Database management
- **data-factory/** - Data integration and ETL pipelines

### Compute & Containers
- **container-instances/** - Serverless container deployment
- **kubernetes/** - Azure Kubernetes Service (AKS)
- **functions/** - Serverless compute functions
- **app-service/** - Web app hosting and management

### Security & Identity
- **key-vault/** - Secrets, keys, and certificate management
- **active-directory/** - Identity and access management
- **managed-identity/** - Azure-managed service identities

### Monitoring & Management
- **monitor/** - Application and infrastructure monitoring
- **resource-management/** - ARM templates and resource operations
- **cost-management/** - Billing and cost optimization

## tofu-aicl Integration

Each API module includes:
- Method documentation with examples
- tofu-aicl provider resource definitions
- Enterprise authentication patterns
- Multi-region deployment strategies
- Cost optimization and governance
- Compliance and security configurations

## Key Features for AI Workflows

- **Enterprise Security**: Azure AD integration and RBAC
- **Hybrid Cloud**: On-premises and cloud connectivity
- **Compliance**: SOC, HIPAA, FedRAMP certifications
- **Global Scale**: Multi-region deployment capabilities
- **Cost Management**: Detailed billing and optimization tools
